JRXDY GAMES — starter website

FILES
- index.html: page structure
- style.css: visual design
- script.js: sample game cards, search, and category filters

PREVIEW
Open index.html in a browser.

ADD A GAME
1. Open script.js in a text editor.
2. Add an object to the `games` array:
   { name: "Game name", category: "Arcade", symbol: "★",
     description: "Short description", url: "https://official-game-link.example",
     glow: "#2868b7" }
3. Use a game you created, have permission to share, or an official link/embed that allows it.
4. Save and refresh the page.

FREE HOSTING WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository named `jrxdy-games`.
3. Upload index.html, style.css, and script.js to the repository's main/root folder.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the `main` branch and `/ (root)`, then Save.
7. GitHub will show the published website address after it finishes deploying.

Note: GitHub Pages hosts static websites. It does not bypass school network restrictions. A school or network may block game sites. Follow school rules and use only games and files you have permission to publish.
